# day05 경보 판단

## 이상한 줄
- 줄 번호(여러 개면 모두): 2번, 3번
- 이유: 인터넷에 있는 외부 PC 192.0.2.7에서 INSIDE 구역의 DB 서버로 3306번 포트 접속을 시도했는데 방화벽에서 허용되었기 때문이다. 구성도에서 WEB 서버는 DMZ에 있고 DB 서버는 내부망(INSIDE)에 있으므로 외부 인터넷에서 DB로 직접 접근하는 통신은 차단되어야 한다.

## 고친 구성도
```
                         ┌── DMZ (WEB: 443 open)
                         │        │
INTERNET ──── FW ────────┤        │ WEB → DB:3306 허용
                         │        ▼
                         └── INSIDE (DB: 3306)
```
