# 정산 포털 정책 로그 점검 결과
## 결론
- 정책 결정과 실제 앱 처리 결과가 일치하지 않거나 정책 기록 없이 처리된 요청이 총 4건 확인되어, 접근 통제의 실제 집행 경로를 우선 점검하고 정상 업무의 불필요한 차단을 줄이는 규칙 조정을 검토해야 한다.
## 근거
- 정책 결정의 집행 누락 2건: 요청 101은 정책 판단 시스템(PDP)이 거부했으나 앱은 200으로 처리했고, 요청 108은 추가확인 결정에도 앱이 200으로 처리했다. 집행 누락은 정책이 요구한 차단 또는 추가 확인보다 약하게 처리된 경우다. 따라서 정책을 실제로 적용하는 지점(PEP)의 설정 및 전달 기록을 확인해야 한다.
- 과집행 1건·우회 의심 1건: 요청 112는 허용 결정인데 앱이 403으로 차단했다. 또한 요청 201은 정책 로그에 없지만 앱에서는 200으로 처리되었다. 우회는 정책 판단을 거치지 않고 앱에 도달하는 경우를 뜻하나, 201번이 실제 우회했는지 또는 정책 로그가 누락되었는지는 아직 확인되지 않았다.
- 규칙 조정의 효과와 부작용: 현재 규칙은 정상 요청을 불필요하게 추가확인·거부한 오탐 6건, 위험 요청을 거부하지 못한 미탐 0건이었다. 조정안 A는 오탐 0건·미탐 1건, B와 C는 각각 오탐 0건·미탐 2건이었다. A안에서도 해외에서 49건을 조회한 위험 요청 11번은 해외 접속 점수 30점만 받아 거부 대신 추가확인이 된다. 오탐은 정상 요청을 불필요하게 제한한 경우, 미탐은 위험 요청을 충분히 차단하지 못한 경우다.
## 권고
- 집행 경로를 우선 점검한다. 요청 101과 108의 집행 누락, 201의 우회 의심을 우선 조사한다. PDP 결정 전달 기록, PEP 정책·집행 로그, 프록시·라우팅 설정 및 앱 접근 로그를 비교하고, 112번 과집행의 설정 오류도 점검한다. 기록만으로 계정 도용이나 실제 우회 여부를 단정하지 않는다.
- 조정안 A를 우선 검토하되 미탐을 보완한다. 비교 대상 11건에서 오탐을 6건에서 0건으로 줄이면서 미탐은 1건으로 B·C보다 적다. 다만 해외 49건 조회(11번)를 추가확인에 그치게 하므로, 해외 접속과 조회량이 결합된 요청에 대한 별도 차단·심사 기준을 마련하고 재시험한 뒤 적용한다.
