# A사 Zero Trust 적용 방안
## 5대 원칙 적용 방안
- ID: 로그인 방식을 비밀번호와 MFA로 로그인 되게 한다.
- Device: 등록된 회사 기기만 접속을 허용하고, 모든 직원의 기기에 대해 백신 실행 여부, 보안 패치 상태 등을 점검하며 기준 미충족 기기는 차단한다.
- Network: 서버 구역과 직원 PC 구역을 나누고, 필요한 포트만 연다
- Application: 재무팀은 정산 포털의 SETTLE만, 영업팀은 영업 앱의 SALES만 조회하도록 권한을 제한하고, 허용 목록에 없는 기능과 자원은 기본 거부한다.
- Policy: 해외 IP/ 새벽 로그인이면 추가 인증이 필요하다.
## 판단과 집행
- PDP(결정): 중앙 접근 정책 판단 시스템에 두고, 사용자의 신원·기기 상태·접근 권한·접속 시간과 위치를 확인하여 허용·추가확인·거부를 결정한다.
- PEP(집행): 정산 포털과 영업 앱 앞의 접근 게이트웨이에 두고, PDP의 결정에 따라 정상 요청만 앱에 전달하고 추가 인증을 요구하거나 접근을 차단하고 로그에 기록한다.
## 흐름도
```
사용자 --요청--> PEP --문의--> PDP
                  ^            |
                  +--- 결정 (허용 / 추가확인 / 거부) +
PEP: 허용 --> 앱 | 추가확인 --> MFA 요구 | 거부 --> 차단하고 로그에 기록
```
## 최소권한 기준 (목록에 없으면 거부)
- 재무팀: SETTLE(정산 내역) 
- 영업팀: SALES(영업 실적)
- 서비스 계정 batch-night: SETTLE
