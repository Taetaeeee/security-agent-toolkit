# 정산 포털 로그 점검 결과 (10/21(수))
## 결론
- 정책 로그 20건에서 거부 8건·허용 12건이 확인됐으며, seoyeon은 미등록 기기에서 거부된 3분 뒤 등록 기기에서 허용됐고 junho는 동일 기기에서 MFA 미실시로 거부된 3분 뒤 허용됐으나 실제 접속자의 신원과 재시도 원인은 추가 확인이 필요합니다.
## 정정 (3-1 에서 읽은 것 중 바뀐 것 · 바뀌지 않은 것)
- 바뀐 것: 3-1에서는 '거부 후 10분 이내 허용' 두 건(seoyeon, junho)만 살펴봤는데, 새 자료에서 기준을 60분으로 넓히자 14:00에 해외 접속으로 거부된 뒤 14:40에 같은 기기 NB-0610으로 허용된 jiho 건이 추가됐습니다. 또 seoyeon의 NB-7741은 회사 기기 등록표에 없는 기기이고, 02:10과 15:20에 같은 계정으로 두 차례 거부됐음이 확인됐습니다.
- 바뀌지 않은 것: 10분과 30분 기준에서 찾은 건은 seoyeon(02:13)과 junho(09:44) 두 건으로 같습니다. seoyeon은 거부 당시 NB-7741에서 허용 당시 NB-0417로 기기가 달랐고, junho는 거부·허용 모두 NB-0522로 같았습니다. 이 기록만으로 계정 도용이나 본인의 정상 재시도 여부를 확정할 수는 없습니다.
## 근거
- 02:10 seoyeon 계정은 미등록 기기 NB-7741에서 거부됐지만 02:13 등록 기기 NB-0417에서 허용됐습니다. NB-7741은 15:20에도 다시 거부돼 미등록 기기 거부가 총 2건입니다.
- 09:41 junho 계정은 NB-0522에서 'MFA 안 함'으로 거부됐으며, 09:44 같은 기기에서 허용됐습니다. 60분 기준으로 넓히면 14:00 '해외 접속' 거부 후 14:40 허용된 jiho(NB-0610) 건도 추가됩니다.
- 전체 20건은 허용 12건·거부 8건이고, 거부 이유별 건수는 다음과 같습니다. 특히 퇴사 계정 dami의 거부가 4건으로 가장 많았고, 10/14 퇴사 이후에도 NB-0333의 기기 등록이 남아 있습니다.
```
미등록 기기 ## 2
퇴사 계정 #### 4
MFA 안 함 # 1
해외 접속 # 1
```
## 권고 (먼저 할 것부터)
1. 조치:④ 퇴사 계정 dami 를 비활성화하고 NB-0333 등록 삭제 / 막을 수 있는 위험:퇴사 뒤에도 계속되는 시도 / 정상 직원에게 생기는 불편:퇴사가 확정이면 거의 없음
2. 조치:② seoyeon 본인에게 연락해 미등록 기기를 아는지 묻고 비밀번호 변경 안내 / 막을 수 있는 위험:계정 정보가 노출됐다면 사전 차단 / 정상 직원에게 생기는 불편:확인 연락 1회, 답이 늦으면 그동안 시도가 계속됨 
3. 조치:⑥ 모든 계정에 MFA(2차 인증 같은 추가 인증)를 항상 요구	 / 막을 수 있는 위험:계정 도용 전반 / 정상 직원에게 생기는 불편:모든 직원이 로그인할 때마다 불편 
## 올리는 조건
- 조건 1: seoyeon이 02:10 또는 15:20의 NB-7741 시도를 본인이 하지 않았다고 확인하거나, 같은 미등록 기기에서 새로운 접속 시도가 다시 기록되면 → 보안 담당자에게 즉시 알리고 해당 계정의 기존 세션 회수 및 임시 계정 잠금을 검토합니다.
- 조건 2: 퇴사 계정 dami에서 거부 이후 '허용' 기록이 새로 확인되거나, 비활성화 후에도 유효 세션의 접근 기록이 나타나면 → 즉시 세션·접근권한을 회수하고 인증·접근 기록을 조사하는 사고 대응 단계로 올립니다.
## seoyeon 본인에게 보낼 확인 메시지
- 안녕하세요. 보안 점검 중 10/21 02:10과 15:20에 seoyeon 계정으로 미등록 기기 NB-7741에서 접속을 시도했다가 거부된 기록을 확인했습니다. 또한 02:13에는 등록 기기 NB-0417에서 접속이 허용된 기록이 있습니다. 두 시각의 접속을 직접 시도하셨는지, NB-7741 기기를 알고 계신지 확인 부탁드립니다. 혹시 본인의 접속이 아니거나 기억나지 않는다면 즉시 알려 주시고 계정 비밀번호를 변경해 주세요. 확인 전까지 다른 사람에게 인증번호나 비밀번호를 전달하지 말아 주세요.
