### 찾아본 것

- 2.1 표에서 찾아 쓴 TTL 의 뜻과 라우터를 지날 때 바뀌는 방식:
    - TTL : Time To Live, 데이터 패킷이 네트워크 상에 무한히 살아남아 도는 것을 방지하기 위해 설정된 수명 값이다.
    - 라우터를 지날 때 바뀌는 방식 : 패킷이 라우터를 통과(홉을 거침)할 때마다 TTL 값은 무조건 1씩 감소한다. 감소하다가 TTL 값이 0이 되면, 라우터는 해당 패킷을 폐기함.

    ESTABLISHED = 연결 수립 완료 상태, 클라이언트와 서버 간의 3-Way Handshake(연결 확인 절차)가 정상적으로 끝나서, 실제 양방향 데이터 송수신이 가능한 상태

### 문제 4-5 · 증상으로 층 좁히기

- 증상 ① · ② · ③ 에서 의심되는 층: 
    ① 7계층 응용계층
    ② 3계층 네트워크계층
    ③ 7계층 응용계층
- 증상마다 그렇게 판단한 근거는 무엇인가요?
  - 답:
    ① IP 통신 자체보다는 DNS(Domain Name Server)과정에 문제가 있을 가능성이 높다. DNS는 도메인 이름을 IP 주소로 변환하는 응용계층 프로토콜이기 때문에 7계층인 응용계층이 의심된다.
    ② 기본 게이트웨이는 다른 네트워크로 패킷을 전달하는 라우터의 IP 주소 이므로, 게이트웨이 IP와 통신하지 못한다면 IP주소, 서브넷 마스크, 기본 게이트웨이 설정 또는 네트워크 연결 상태를 점검해야한다. 실제 장애 분석에는 ARP, 스위치, 무선 연결 등 1~2계층 문제도 확인해야 한다.
    ③ ping은 되는데 특정 웹사이트가 안열리는 것이면 하위계층인 기본적인 네트워크 연결은 정상일 가능성이 높다. 따라서 HTTP/HTTPS 서비스, 웹서버 상태, TLS 인증서, 브라우저 및 웹 필터링과 같은 7계층인 응용계층이 의심된다.

### 찾아본 것

- 4.1 표에서 찾아 쓴 3389 의 위험과 445 를 이용해 퍼진 랜섬웨어:
    3389 포트는 윈도우 운영체제의 원격 데스크톱 프로토콜(RDP, Remote Desktop Protocol)이 기본적으로 사용하는 통신 포트이다. 해당 포트는 공격자들이 자동 스캔 프로그램으로 무작위 비밀번호 대입(브루트 포스)이나 랜섬웨어를 유포하기 위해 자주 노리는 대상이다.

    445번 포트는 윈도우 운영체제에서 SMB(Server Message Block) 및 Microsoft-DS 서비스에 사용되는 TCP 네트워크 포트이다.
        포트 445(TCP)를 이용하여 전 세계적으로 대규모 감염을 일으킨 가장 대표적인 랜섬웨어는 워너크라이(WannaCry)이다.
        오래된 버전의 SMB를 실행하는 Windows 클라이언트를 표적으로 삼았다. 웜 감염이 대상 시스템에 설치되어 몸값을 요구하는 대가로 사용자의 파일을 암호화했다.


### 이 교시에 새로 안 것

- 이 교시에서 새로 알게 된 것: 기본적인 22, 53, 80, 443 포트번호 뿐만 아니라 다양한 포트번호들인 3389, 135, 445를 알게 되었다. 또한 네트워크 증상이 생겼을 때 어느 계층에서 문제가 생겼을 지 판단할 수 있는 근거를 알게 되었다.

### 문제 5-3 · 세 번의 순서 맞히기

- 세 패킷의 순서와 방향: (나) [SYN] -> (다) [SYN, ACK] -> (가) [ACK]
