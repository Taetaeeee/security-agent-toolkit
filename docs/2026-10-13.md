# 2026-10-13 (화)

## 오늘 새로 쓴 명령
cat, grep

## 오늘 쓴 옵션
- `-n` : 찾은 줄에 줄 번호를 붙인다
- `-c` : 조건에 맞는 줄 수를 숫자로 보여 준다

## 찾아보고 알게 된 것

grep 은 리눅스에서 파일이나 명령어 출력 내용 중 특정 문자열 또는 패턴이 포함된 줄을 검색하는 명령어입니다.

**명령 결과**

cat sample.log 를 실행하면 아래 여섯 줄이 나옵니다.

```text
09:00 로그인 성공
09:03 로그인 실패
09:10 와이파이 연결
09:12 와이파이 끊김
09:20 로그인 실패
09:25 인터넷 연결
```

grep "실패" sample.log 결과:

```text
09:03 로그인 실패
09:20 로그인 실패
```

grep -n "끊김" sample.log 결과:

```text
4:09:12 와이파이 끊김
```

grep -c "실패" sample.log 결과:

```text
2
```

## 막힌 것

- 서브넷 마스크에 따라 같은 IP 주소도 같은 망인지 다른 망인지 판정이 달라지는 부분이 헷갈렸다.
- 다른 망으로 패킷을 보낼 때 기본 게이트웨이를 거치는 과정과 라우팅 테이블의 `0.0.0.0/0`이 어떤 역할을 하는지 이해하기 어려웠다.
- VLAN으로 부서별 네트워크를 분리했을 때 회사 내부의 다른 부서로 통신하는 경우에도 게이트웨이를 거쳐야 하는 이유가 헷갈렸다.
- ARP 스푸핑으로 게이트웨이의 MAC 주소가 잘못 저장되면 패킷이 어떻게 다른 장비로 전달되는지 이해하기 어려웠다.
