# 2026-10-08 (목)

## 오늘 새로 쓴 명령

git config, git add, git commit, git push

## 찾아보고 알게 된 것

add는 변경한 파일을 선택하고, commit은 그 변경 사항을 로컬 저장소에 기록하며, push는 커밋한 내용을 원격 저장소에 올리는 명령이다.

untracked는 아직 Git이 관리하지 않는 파일, tracked는 Git이 관리 중인 파일, staged는 다음 commit에 포함되도록 준비된 상태이다.

git status로 현재 파일 상태를 확인할 수 있다.

## 막힌 것

add, commit, push의 역할과 untracked, tracked, staged의 차이가 헷갈렸다.

## 다음에 확인할 것

git status로 파일 상태가 어떻게 바뀌는지 확인하기.
