## **찾아보고 알게 된 것**
저장소와 내 폴더는 처음부터 자동으로 연결되어 있는 것이 아니라, 로컬 폴더를 Git 저장소로 만들고 원격 저장소를 연결해야 한다.

`git init`으로 현재 폴더를 Git 저장소로 만들고, `git remote add`로 GitHub 저장소를 연결한다.

`git fetch`는 원격 저장소의 내용을 가져오지만 바로 내 파일을 바꾸지는 않고, `git reset`을 이용하면 특정 원격 상태에 로컬을 맞출 수 있다.

`git branch -u`로 로컬 브랜치가 어떤 원격 브랜치를 따라갈지 지정할 수 있고, `git status`로 현재 파일과 Git 상태를 확인할 수 있다.

많은 경보를 LLM에 한 번에 보내기보다 여러 묶음으로 나눠 처리하는 배치 처리 방식을 배웠다. 18개의 경보를 6개씩 나눠 LLM에 보내 요약했다.

`json.dumps()`는 파이썬 값을 JSON 문자열로 바꾸고, `json.dump()`는 JSON 데이터를 파일에 저장할 때 사용한다.

LLM이 만든 요약에 원래 없던 id가 생기거나 기존 경보가 빠졌는지 비교하여 확인하는 방법을 실습했다.

위험도는 `high`, `medium`, `low` 순서로 정리하고, `.lower()`를 사용하면 `High`, `HIGH`처럼 대소문자가 달라도 같은 값으로 비교할 수 있다.
