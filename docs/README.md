## 기록 방식

날짜별 문서는 주로 다음 내용을 기준으로 작성했습니다. 날짜에 따라 설치한 도구, 찾은 옵션, 실습 결과와 추가 설명을 함께 기록했습니다.

| 항목 | 기록 내용 | 문서에 담긴 사례 |
| --- | --- | --- |
| 오늘 새로 쓴 명령 / 오늘 한 것 | 처음 사용한 명령어와 직접 수행한 실습 | Git 명령, Webhook 요청, API 호출, 파일 처리와 편집 |
| 찾아보고 알게 된 것 / 찾아본 것 | 새롭게 이해한 개념과 명령의 역할 | JSON 변환, HTTP 응답, 함수 등록, 패킷 분석과 DNS |
| 막힌 것 | 실행 중 발생한 오류와 이해하기 어려웠던 부분 | `KeyError`, 포트 중복, 상태 코드 비교, Git 파일 상태, 경로와 `vim` 모드 혼동 |
| 다음에 확인할 것 | 추가로 확인하거나 복습할 내용 | 재시도, JSON 예외 처리, 서브넷 계산, 로그 검색, 파일 백업 |

## 1과목 회고

[`day08_retrospective.md`](./day08_retrospective.md)는 9월 22일부터 10월 8일까지 진행한 1과목 전체 과정을 정리한 회고 문서입니다.

주요 내용은 다음과 같습니다.

- Python 기초부터 보안 로그 분석까지의 학습 과정
- 로그 파싱과 JSON 정규화
- 정규표현식 기반 보안 탐지
- API 및 Webhook 연동
- Scheduler를 이용한 자동 실행
- Gemini API와 LLM 분석
- 경보 위험도 분류와 관제 보고서 생성
- 설정·알림·보고서를 연결한 Pipeline 구성
- `assert`를 이용한 테스트와 디버깅
- 캡스톤에서 추가로 구현하고 싶은 기능
